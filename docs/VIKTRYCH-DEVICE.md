# Set up this device

Ask Viktrych “set up this device” (or the same idea in Spanish, Russian, or Hindi). Owner switch: `ai_device_setup`.

The page reads only what this browser reports: connection type, data saver, effective network type, memory, processor cores, reduced motion, whether vibration exists, and a battery reading when the page already has one. It then lists app settings that would suit that device and, when the link is cellular, slow, or data-saver, a non-Wi-Fi plan. Each row says why. Clear a row to leave that setting alone. Apply writes the ticked rows. Undo device setup puts the previous values back.

If the browser does not say Wi-Fi or cellular, the card asks you to pick: cellular data plan, Wi-Fi, or not sure. “Not sure” changes only device settings such as motion and vibration.

These are never changed here, and the card says so:

- Carrier plan, data cap, and APN.
- The phone’s Low Data Mode, background data, and system battery saver.
- Notification, camera, microphone, and location permission prompts.
- The phone’s own autoplay switch.

Data saver in the browser is not treated as the name or size of a carrier plan.
